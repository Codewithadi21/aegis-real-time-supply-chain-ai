01 · Why it matters

Valid data can still be semantically wrong.

The feature engagement_events_30d originally counted purchases, but an upstream change made it count logins while preserving its field name and integer type. Conventional validation still passed. The churn model interpreted this new meaning as purchase activity.

TRUSTED INPUT

Engagement = purchases

Baseline feature definition understood by the trained model.

SILENT CHANGE

Engagement = logins

Same field name, same data type, different business meaning.

A successful ETL job is not proof that downstream features preserve their intended business meaning.

04 · Industry potential

Guard the meaning of decision-critical data.

DataPulse illustrates an investigation pattern useful for data engineers, analytics platforms and MLOps teams. The scenarios below are possible applications, not validated customer deployments.

Financial risk

Investigate producer definition changes that affect risk and fraud model features.

Retail / retention

Trace unexpected customer scoring changes back to upstream feature semantics.

Supply chain

Validate metrics that influence demand, delivery-risk or inventory predictions.

Industry-ready evolution would require automatic lineage, continuous monitoring, idempotent event processing, access control, observability, alerting, and operational review. The current version is a one-shot educational prototype.

06 · Interview pitch

Explain it in 90 seconds.

“I developed DataPulse AI to investigate a blind spot in data engineering: a source can preserve a valid schema while silently changing a feature’s business meaning. I reproduced that scenario using synthetic customer data, a fixed churn model and the same holdout customer cohort. Technical checks passed but semantic checks failed; 340 predictions changed, while ROC-AUC fell from 0.8157 to 0.5414. The solution produces an evidence-first incident report, with optional BigQuery and Pub/Sub integrations. Importantly, these are controlled synthetic outcomes, not claims of real customer harm.”
